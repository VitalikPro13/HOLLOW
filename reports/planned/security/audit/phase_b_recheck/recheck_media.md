# Phase B re-check: authz_media.md (calls, voice channels, screen share, forwarder, SFrame)

Re-checked 2026-10-02 against the working tree (HEAD d16deefe). Read-only. Rust paths are
relative to `rust/hollow_core/src/`, Dart paths to the repo root. Every cited line was read.

Two cross-cutting facts used by many rows:

- **Every relay frame is opened against its sealed sender before parsing.** `node/swarm.rs:4830`
  `let (frame_ts, frame_nonce, data) = match super::frame_auth::open(&data, &from, &room, delivery, now_ms) {`
  then live-only frames are freshness and replay checked, `swarm.rs:4875-4877`
  `if msg.live_only() && (super::frame_auth::is_stale(frame_ts, now_ms) || !frame_replays.first_sight(&from, frame_nonce, frame_ts, now_ms))`.
  A hostile relay can no longer choose `peer_str` for a main-node frame (HOL-SEC-053).
- **The lane gate.** A plaintext frame whose `lane()` is not `Relay` is dropped before any handler:
  `swarm.rs:5181-5184` `} else if msg.lane() != Lane::Relay { ... "Dropped a plaintext {} from {from}: it rides Olm only"`.
  Voice presence/state are `Lane::Carried` (`node/types.rs:4084-4089`), every `Call*` is
  `Lane::CallSignal` (`types.rs:4138-4155`), the six `Rtc*` stay `Lane::Relay` (`types.rs:4188-4193`).
  A carried message is re-dispatched only if its lane is `Carried` (`swarm.rs:8890`
  `} else if msg.lane() == Lane::Carried {`), and a carried live-only message is judged by the
  inner message's time (`types.rs:4327` `Self::Carried { msg, .. } => msg.live_only(),`,
  `swarm.rs:7461-7470` `.min(frame_ts_ms)` ... `"Dropped a live signal from {peer_str} that arrived too late"`).
