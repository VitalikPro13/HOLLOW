# Transparency Report

**Last updated: October 19, 2026**

Hollow has received 0 legal requests. 

*Our relays pass along end-to-end encrypted traffic they cannot read. When someone is offline, the relay holds the encrypted traffic meant for them in memory for a limited time, so they can pick it up when they come back, and never writes it to disk. The only thing a relay writes to disk is an anonymous count of reports and blocks for each reported account, with no record of who reported or blocked whom. The source code is [available.](../relay-uws/) If we receive any legal reports, they will be publicly available here.*
